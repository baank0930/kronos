# Kronos mini・small 比較アプリ

新規GitHubリポジトリからStreamlit Community Cloudにデプロイする、1銘柄の研究用アプリです。mini・smallの5系列を表示し、1〜5営業日先の比較、日別OHLC・高安幅、同一起点での過去検証を行います。売買注文の機能はありません。

## ファイル構成

```text
新規リポジトリ/
├── app.py                 ← Streamlitの起動ファイル
├── requirements.txt       ← 必要ライブラリ
├── README.md              ← この説明
└── kronos_engine/
    ├── __init__.py
    ├── kronos.py
    ├── module.py
    └── LICENSE
```

## 1. 新規GitHubリポジトリを作成

1. GitHubで新しいリポジトリを作成します。リポジトリ名は自由です。
2. 配布されたZIPを展開します。
3. 展開したファイル・フォルダを、上記の構成でリポジトリ直下へ追加します。`app.py` と `requirements.txt` がリポジトリの一番上にあること、`kronos_engine` 内に4ファイルがあることを確認してください。
4. 変更をコミットします。**ZIPそのものだけをアップロードしてもアプリは動きません。**

GitHubのWeb画面で操作する場合は「Add file」→「Upload files」からアップロードできます。フォルダをアップロードする際は、コミット後に `kronos_engine/kronos.py` などの階層が保たれているか確認してください。

## 2. Streamlit Community Cloudへデプロイ

1. Streamlit Community Cloudにログインし、新しいアプリの作成画面を開きます。
2. 作成したGitHubリポジトリとブランチ（通常 `main`）を選びます。GitHubへのアクセス許可を求められたら、対象リポジトリを許可します。
3. Main file pathに **`app.py`** を指定します。
4. Advanced settingsでPython **3.12** を選択します（本構成は3.10〜3.13を想定）。
5. Deployを実行し、環境構築とアプリの起動を待ちます。通常、SecretsやAPIキーの設定は不要です。

以後のコード変更は、このリポジトリと選択したブランチにコミットします。既存の別アプリや、そのリポジトリを変更する必要はありません。

自分だけで使いたい場合は、デプロイ先のアプリの公開範囲・アクセス設定を必ず確認してください。GitHubリポジトリを非公開にしただけで、アプリのURLへのアクセスが制限されるとは限りません。

## 3. アプリの使い方

1. ティッカーを入力します。例：米国 `SPY`、日本 `1320.T`、台湾 `0050.TW`。
2. 予測営業日数（1〜5日）を選びます。
3. 「過去検証の起点数」は、最初は初期値の **0** のまま予測のみで動作確認してください。問題がなければ10起点などで試します。40〜60起点はCPUで非常に時間がかかる場合があります。
4. 「予測・比較を実行」を押します。初回実行時はモデルの重みをダウンロードします。
5. mini・smallの各5系列、日別OHLC・高安幅・MA10、過去検証などを確認します。結果はCSVで保存できます。

過去検証の主比較は、両モデルの**全起点・同一実績**の表で確認してください。±0.5%以上の方向別表はモデルごとに対象起点が異なることがあります。

## 注意事項

- 初回デプロイでは、CPU版PyTorchなどのライブラリをインストールします。初回予測時にはモデルもダウンロードします。時間・ディスク・メモリが必要です。Community Cloudの資源上限により、デプロイや実行が停止する場合があります。
- データはyfinanceの調整済み日足です。遅延、欠損、利用条件に注意してください。直近の取引終了日よりデータが古い場合は画面に警告します。
- 米国はNYSEカレンダー、台湾店頭は台湾上場市場のカレンダーで近似します。臨時休場や実際の取引日を保証できません。
- 5系列はモデルからのサンプルであり、上昇確率や予測区間ではありません。出力に高値・安値・出来高の不整合がある場合は警告します。予測を売買判断や注文に直結しないでください。
- 公式Kronosのコードはコミット `67b630e67f6a18c9e9be918d9b4337c960db1e9a` を同梱し、importを相対パスに変更しています。コードのライセンスは `kronos_engine/LICENSE`、モデル重みの条件はHugging Faceの各モデルで確認してください。
- 人工データと模擬モデルを使い、アプリの画面・比較計算をテストしています。**実モデルを使ったStreamlit Community Cloud上での実行は未確認**です。

## ローカルで起動する場合

Python 3.12の環境で、このフォルダを開き次を実行します。`requirements.txt` はLinux向けCPU版PyTorchを指定しています。OSやPython環境によってはPyTorchのインストール設定を変更してください。

```bash
pip install -r requirements.txt
streamlit run app.py
```
